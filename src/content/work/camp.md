## Campus reservations and inventory

I built CAMP with a five-person software engineering team. The app lets students browse and reserve equipment while staff manage inventory, issue items, and record returns.

## My implementation

I implemented Express.js REST endpoints for staff workflows, equipment alerts, and dashboard statistics. I wrote Mocha/Chai integration tests and client API functions, including token handling and authentication-error handling.

I also served as Product Owner in Sprint 1 and Scrum Master in Sprint 3.

## Application structure

I worked within a React frontend, an Express API on Node.js, and a MongoDB data layer. The app uses JWT authentication and role-based access for student and staff operations, with booking-conflict checks.
